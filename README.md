# Open Nini

An open-source Farsi app for [Ninisite](https://www.ninisite.com/discussion) discussions.

From the home screen you open a discussion, then its boards, then a thread and its posts. You can sign in, create an account, post in discussions, and open your profile from the bottom bar. Messages are a separate section: search for someone by nickname, see a pending friend request in the chat list, and chat after they accept.

## Download

Android builds are on the [releases page](https://github.com/mtrbpr/open-nini/releases). Download the APK (currently `nini-0.6.0.apk`) and allow installation from this source.

An iOS install file is not in the current release. The iOS project is in this repository and can be opened in Xcode.
