# Open Nini

An open-source Farsi app for [Ninisite](https://www.ninisite.com/discussion) discussions.

From the home screen you open a discussion, then its boards, then a thread and its posts. You can sign in, create an account, open your profile, and post in discussions. Messages are a separate section: search for someone by nickname, then chat after they accept a friend request.

## Download

Android builds are on the [releases page](https://github.com/mtrbpr/open-nini/releases). Download the APK (currently `nini-0.5.0.apk`) and allow installation from this source.

An iOS install file is not in the current release. The iOS project is in this repository and can be opened in Xcode.
